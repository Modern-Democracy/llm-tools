# Core Module

This module defines the minimum project structure for an LLM-assisted software project.

## Provides

- Canonical project model files.
- Role-gated delivery workflow.
- Project decision records.
- Wiki scaffold and maintenance rules.
- Source layout conventions.

## Rules

- Start work by classifying objective, scope, affected artifacts, ambiguity, and next role.
- Resolve product and behavior ambiguity before implementation.
- Resolve architecture and schema decisions before implementation.
- Keep durable knowledge in the wiki.
- Finish implementation work with QA evidence.
- Keep generated artifacts separate from canonical files.
